# Что нужно исправить:

• Проблема производительности (UI Lag): Обновление стейта React (setScrollPercentage) происходит синхронно на каждый пиксель прокрутки (внутри события scroll). Это заставляет React запускать тяжелые фазы сверки (reconciliation) многократно в секунду, вызывая пропуски кадров (jank).
• Оптимизация: Вместо стейта React для анимации индикатора прогресса эффективнее использовать прямой доступ к DOM через useRef и обновлять style.width внутри коллбэка requestAnimationFrame. Это синхронизирует перерисовку с частотой обновления экрана.

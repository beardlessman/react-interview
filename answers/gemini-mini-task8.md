# Что нужно исправить:

• Критический баг (Пакетное обновление на старых данных): Все три промиса запускаются одновременно. Внутри каждого из них выражение setUploadedCount(uploadedCount + 1) видит старое значение uploadedCount, равное 0 (на момент клика). Когда все три запроса завершатся, они по очереди установят 0 + 1 = 1. Вместо ожидаемых 3 на экране отобразится 1.
• Оптимизация / Исправление: Заменить на функциональное обновление состояния: setUploadedCount(prev => prev + 1). Это гарантирует, что каждый инкремент будет работать с самой актуальной версией стейта из очереди обновлений React.

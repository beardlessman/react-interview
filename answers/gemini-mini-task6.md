# Что нужно исправить:

• Критический баг (Рассинхронизация состояния): Когда пользователь нажимает кнопку "Clear", код напрямую очищает inputRef.current.value = ''. Однако эта мутация DOM происходит в обход стейта React. Компонент не перерендеривается, событие onChange не срабатывает, и кнопка Submit остается активной (isFormValid === true), хотя поле ввода уже абсолютно пустое.
• Оптимизация / Архитектурный фикс: Использовать контролируемый инпут через стандартный useState для значения строки (value + onChange). Прямые мутации DOM через рефы для изменения UI-данных — это антипаттерн в React.

# Что нужно исправить:

• Проблема производительности (Лишние ререндеры контекста): Объект value={{ user, theme, toggleTheme }} создается заново при каждом изменении состояния theme или user. Хуже того, любой компонент, подписанный на AppContext (как UserProfileButton), будет принудительно перерендериваться при изменении любой части контекста. Клик по кнопке смены темы заставит перерисоваться профиль пользователя.
• Оптимизация:
	1. Обернуть передаваемый объект в useMemo.
	2. Разделить контекст на два независимых: UserContext и ThemeContext, чтобы изменения темы не затрагивали компоненты, работающие только с пользователем.

# Экзамен по JavaScript

Типичные вопросы с краткими ответами.

## Синтаксис и база

### Способы создания (объявления) переменной? Разница между `var`, `let` и `const`?

- `var` — function scope, поднимается, можно переобъявлять.
- `let` — block scope, TDZ до объявления, нельзя переобъявлять в той же области.
- `const` — как `let`, но нельзя переназначить привязку (содержимое объекта менять можно).

Var — до ES6
Переменные var можно объявлять без присвоения им значения (будет undefined)
имеют функциональную область видимости
Они доступны только в пределах текущей функции или глобального объекта, если функции нет
Объявление var вне функций делает её глобальной переменной
можно обращаться до момента объявления (всплытие переменной)

Const не объявляется без значения, в отличии от let
К переменным let и const нельзя обращаться до их объявления в коде
Оба типа переменных имеют блочную область видимости и не становятся частью глобального объекта. Блочная область видимости не даёт получить значение переменной вне блока, где она была объявлена.
Подробнее: https://doka.guide/js/var-let/


### Объясните концепцию «поднятия» (hoisting)

Объявления «поднимаются» вверх области видимости. У `var` поднимается объявление со значением `undefined`. У `let`/`const` тоже есть hoisting, но до строки объявления действует TDZ — обращение вызовет ошибку. Function declaration поднимается целиком.

### Перечислите все типы данных в JavaScript

Примитивы: `string`, `number`, `bigint`, `boolean`, `undefined`, `symbol`, `null`.  
Непримитив: `object` (включая массивы, функции, даты и т.д.).

### Как узнать тип переменной? Что возвращает `typeof`?

`typeof value` возвращает строку: `"string"`, `"number"`, `"boolean"`, `"undefined"`, `"object"`, `"function"`, `"symbol"`, `"bigint"`.

### Что вернёт `typeof null`?

`"object"` — историческая ошибка языка. Проверять так: `value === null`.

### Что такое `NaN`? Какого типа? Как проверить равенство `NaN`?

`NaN` — «not a number», тип `number`. `NaN === NaN` → `false`. Проверки: `Number.isNaN(x)` или `Object.is(x, NaN)`.

### Какие унарные операторы вы знаете?

`+`, `-`, `!`, `typeof`, `void`, `delete`, `++`, `--`, `~`, `await`.

### Какие бинарные операторы вы знаете?

Арифметика: `+ - * / % **`  
Присваивание: `= += -= *= ...`  
Сравнение: `== === != !== < > <= >=`  
Логика: `&& || ??`  
Битовые: `& | ^ << >> >>>`  
Прочее: `in`, `instanceof`.

### Тернарный оператор, синтаксис?

```js
условие ? значениеЕслиTrue : значениеЕслиFalse
```

### Преобразование типов. Строки!

`String(x)`, `x.toString()`, конкатенация `"" + x`, шаблон `` `${x}` ``.

### Преобразование типов. Числа!

`Number(x)`, `+x`, `parseInt(x, 10)`, `parseFloat(x)`, `x * 1`. Пустая строка → `0`, нечисловая → `NaN`.

### Преобразование типов. Логическое!

`Boolean(x)`, `!!x`. Falsy: `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`. Остальное — truthy.

### Какие операторы сравнения вы знаете?

`==`, `===`, `!=`, `!==`, `<`, `>`, `<=`, `>=`.

### Что возвращают операторы сравнения?

Всегда `boolean`: `true` или `false`.

### Сравнение разных типов?

При `==` типы приводятся (часто к числу). При `<`/`>` тоже может быть ToPrimitive/ToNumber. Надёжнее сравнивать одинаковые типы через `===`.

### В чём разница между `==` и `===`?

`==` — нестрогое, с приведением типов. `===` — строгое, без приведения (плюс `Object.is` отличает `-0` и `NaN`).

### Как избежать проблем при сравнении?

Использовать `===` / `!==`, явно приводить типы, для `NaN` — `Number.isNaN`, для объектов — сравнивать по значению отдельно.

### `if else` statement?

```js
if (условие) {
  // ...
} else if (другое) {
  // ...
} else {
  // ...
}
```

Условие приводится к boolean.

### Какие логические операторы вы знаете?

`&&`, `||`, `!`, `??` (nullish coalescing).

### В чём особенность каждого логического оператора?

- `&&` — вернёт первый falsy или последний операнд.
- `||` — вернёт первый truthy или последний операнд.
- `!` — логическое отрицание, всегда boolean.
- `??` — берёт правый операнд только если левый `null` или `undefined`.

### Что возвращают логические операторы?

`&&` и `||` / `??` возвращают **один из операндов**, не обязательно boolean. `!` возвращает boolean.

### Что такое оператор нулевого слияния?

`??` — `a ?? b`: если `a` равен `null`/`undefined`, результат `b`, иначе `a`. В отличие от `||`, не срабатывает на `0`, `""`, `false`.

### Для чего нужен `switch`?

Выбор ветки по значению выражения вместо длинной цепочки `if/else`.

### Ключевые слова в `switch`

- `switch` — выражение для сравнения
- `case` — вариант
- `break` — выход (без него — fall-through)
- `default` — ветка по умолчанию

### Как происходит сравнение в `switch`?

Строгое сравнение (`===`) значения `switch` со значениями `case`.

## Функции

### Для чего нужны функции?

Переиспользовать код, делить программу на части, принимать аргументы и возвращать результат.

### Способы объявления функции? Особенность каждого?

1. **Function declaration** — поднимается целиком.  
2. **Function expression** — `const f = function() {}` — не вызывается до присваивания.  
3. **Arrow function** — `() => {}` — свой `this`/`arguments` нет.  
4. **Method in object** — `obj.method()`.  
5. **Constructor / class method**.

### Как передать параметры в функцию?

В скобках при объявлении и при вызове: `function f(a, b) {}` → `f(1, 2)`. Есть default params, rest `...args`.

### Что можно передавать в качестве параметра?

Любое значение: примитивы, объекты, массивы, функции, `undefined`.

### Как вернуть значение из функции?

`return value;`. Без `return` вернётся `undefined`.

### Что такое стрелочные функции и чем отличаются?

Короткий синтаксис, лексический `this`, нет своего `arguments`, нельзя как `constructor`, нет `prototype`.

### Что такое рекурсия? Когда применяется? Пример структуры?

Функция вызывает саму себя. Нужна для деревьев, факториала, обхода вложенных объектов. Пример структуры: DOM, файловое дерево, JSON со вложенностью.

### Область видимости переменных?

Где переменная видна: global, function (`var`), block (`let`/`const`). Внутренняя область видит внешнюю (scope chain).

“Коробки” внутри которых есть доступ к переменным.
Глобальная: переменные доступны из любой части программы
Модульная: переменная доступна в рамках es-модуля
Блочная: conts доступна внутри скобок { }, например в if/switch case 
Функциональная: в рамках теля функции
Для реализации областей используется лексическое окружение: отслеживает область видимости переменных и функций в определенной точке кода. Так же лексическое окружение хранит ссылку на внешнее/родительское лексическое окружение, поэтому функция может обращаться к внешним переменным.
Области видимости позволяют разграничивать доступ к данным, структурировать код. Одним из наиболее интересных примеров использования механизма областей видимости является замыкание (closure).

### Что такое замыкания? Почему важны? Пример?

Функция «помнит» переменные внешней области после её завершения. Важно для колбэков, модулей, каррирования, `once`/`memoize`.

```js
function makeCounter() {
  let n = 0;
  return () => ++n;
}
```

Замыкание — когда функция «помнит» переменные из внешней области видимости, даже после того как внешняя функция уже завершилась. Часто используют, чтобы сохранить доступ к значениям из внешней области видимости и не выносить их в глобальную область. Замкнутые переменные никак нельзя изменить, кроме как дочерними функциями. Каждый новый вызов создаёт отдельную область, в которой значения абсолютно независимы друг от друга. Сохраняется доступ к переменной на чтение.

### Что такое IIFE? Когда применяется?

Immediately Invoked Function Expression: `(function(){ ... })()`. Раньше — своя область видимости / модуль без загрязнения global.

### Какого типа данных функция?

`typeof fn === "function"` (подтип объектов).

### Можно ли функции назначить свойства? `name`? `length`?

Да, функция — объект. `name` — имя, `length` — число объявленных параметров (до rest/defaults в типичном случае). Свои свойства тоже можно вешать.

### Что такое `setTimeout`? Для чего?

Планирует колбэк один раз через N мс (в event loop). `const id = setTimeout(fn, 1000)`.

### Что такое `setInterval`? Для чего?

Повторяет колбэк каждые N мс. `setInterval(fn, 1000)`, останавливается через `clearInterval`.

### Принципы ООП

Инкапсуляция, наследование, полиморфизм (иногда абстракция). В JS — прототипы / `class`.

### Принципы функционального программирования

Чистые функции, неизменяемость, функции высшего порядка, композиция, избегать побочных эффектов.

### Расскажите про `this` и контекст

`this` зависит от способа вызова: метод объекта → объект; обычный вызов → `undefined`/global; `new` → новый экземпляр; `call`/`apply`/`bind` — явно; стрелка — лексический `this`.

### `call`, `apply`, `bind` — для чего?

Явно задать `this`.  
`call(thisArg, a, b)` — аргументы списком.  
`apply(thisArg, [a, b])` — массивом.  
`bind(thisArg, ...)` — новая функция с привязанным `this` (и частично аргументами).

### Особенности стрелочных функций (`this`, `arguments`)? Как изменить контекст?

Свой `this`/`arguments` не создают — берут из внешней функции. `call`/`apply`/`bind` **не меняют** `this` стрелки. Чтобы «сменить контекст» — обернуть в обычную функцию или не использовать стрелку.

## Числа, строки

### Типы чисел в JS?

`number` (IEEE-754 double) и `bigint`.

### Особенности каждого типа?

`number` — до `Number.MAX_SAFE_INTEGER`, есть `NaN`/`Infinity`, неточные дроби (`0.1+0.2`). `bigint` — целые произвольной длины, суффикс `n`, нельзя смешивать с `number` в арифметике без преобразования.

### Что такое `NaN`? Какой тип данных?

«Not a Number», тип `number`.

### Как получить `NaN`?

`Number("abc")`, `0/0`, `Math.sqrt(-1)`, `parseInt("x")`.

### Что такое `Infinity`? Какой тип?

Бесконечность, тип `number`. Пример: `1/0`.

### Проверка на `NaN` и `Infinity`?

`Number.isNaN(x)`, `Number.isFinite(x)`, `Number.isInfinity` нет — используй `x === Infinity` или `!Number.isFinite(x) && typeof x === "number"`.

### Как работает `parseInt()`?

Читает целое с начала строки, останавливается на первом неподходящем символе. Второй аргумент — radix (`parseInt("10", 10)`).

### Как работает `parseFloat()`?

Читает число с плавающей точкой с начала строки.

### Что такое `Math`?

Встроенный объект с математическими константами и функциями (`PI`, `sqrt`, `abs`…).

### Для чего `Math.max` / `Math.min`?

Максимум / минимум из аргументов. Для массива: `Math.max(...arr)`.

### Для чего `Math.pow`?

Возведение в степень: `Math.pow(2, 10)` ≡ `2 ** 10`.

### `Math.floor`, `ceil`, `round`, `trunc`?

- `floor` — вниз  
- `ceil` — вверх  
- `round` — к ближайшему  
- `trunc` — отбросить дробную часть  

### Как объявить `BigInt`?

```js
const x = 10n;
const y = BigInt(10);
```

### Как создать строку?

`'...'`, `"..."`, `` `...` ``, `String(x)`, `new String(x)` (объект — лучше не использовать).

### В чём особенность обратных кавычек?

Шаблонные строки: интерполяция `${expr}`, многострочность.

### Как вычислить длину строки?

`str.length` (в UTF-16 code units).

### Как достучаться к символу в строке?

`str[i]` или `str.charAt(i)`. Строки неизменяемы.

### Для чего `.toLowerCase()` / `.toUpperCase()`?

Регистр символов. Возвращают **новую** строку.

### `slice()` — для чего? Параметры? Что возвращает?

Вырезает подстроку. `slice(start, end?)` — `end` не включительно. Возвращает новую строку. Поддерживает отрицательные индексы.

### `substring`, `substr`, `indexOf`, `lastIndexOf`, `includes`, `startsWith`, `endsWith`, `trim`

| Метод | Назначение | Возврат |
| --- | --- | --- |
| `substring(a, b)` | подстрока между индексами (отрицательные → 0) | строка |
| `substr(start, length)` | устарел; start + длина | строка |
| `indexOf(sub, from?)` | индекс первого вхождения | число / -1 |
| `lastIndexOf(sub)` | индекс последнего | число / -1 |
| `includes(sub)` | есть ли подстрока | boolean |
| `startsWith` / `endsWith` | начинается / заканчивается | boolean |
| `trim()` | убрать пробелы по краям | новая строка |

### `repeat()`, `split()`

- `repeat(n)` — повторить строку n раз.  
- `split(separator?, limit?)` — разбить на массив строк.

### Как сравниваются строки?

По кодовым единицам Unicode (лексикографически). `"a" < "b"`. Для локали — `localeCompare`.

## Циклы

### Для чего нужны циклы?

Повторять код, пока условие истинно / пока не обойдены элементы.

### Какие виды циклов есть в JavaScript?

`for`, `while`, `do...while`, `for...of`, `for...in`. Плюс методы массивов (`forEach`, `map`…).

### Синтаксис `for`? Что в скобках?

```js
for (инициализация; условие; шаг) { тело }
```

Инициализация один раз, условие перед каждой итерацией, шаг после тела.

### Можно ли опустить части `for`? Если условие не указать?

Да: `for (;;)` — бесконечный цикл (условие считается `true`).

### Синтаксис `while`? Чем отличается от `for`?

```js
while (условие) { тело }
```

Нет встроенных инициализации/шага — ими управляешь сам.

### Синтаксис `do...while`? Чем отличается от `while`?

```js
do { тело } while (условие);
```

Сначала тело, потом проверка условия.

### В каком случае `do...while` выполнит тело хотя бы один раз?

Всегда — даже если условие сразу ложно.

### Что такое бесконечный цикл? Как получить? Как остановить?

Цикл без выхода: `while(true)`, забытый инкремент. Остановить: `break`, изменить условие, `return`, в браузере — убить вкладку; в Node — прервать процесс.

### Для чего `break`?

Немедленно выйти из цикла / `switch`.

### Для чего `continue`? Чем отличается от `break`?

Пропустить остаток текущей итерации и перейти к следующей. `break` завершает цикл целиком.

### Метки (labels)? `break label` / `continue label`?

Имя перед циклом: `outer: for (...)`. `break outer` выходит из внешнего цикла, `continue outer` — к следующей итерации внешнего.

### Как перебрать массив циклом `for`?

```js
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}
```

### Как перебрать массив / объект / строку через `for...of`?

```js
for (const item of arr) {}
for (const ch of str) {}
for (const value of Object.values(obj)) {}
```

### Что перебирает `for...of`? Можно ли для обычного объекта?

Итерируемые значения (`Array`, `String`, `Map`, `Set`…). Обычный объект **не** итерируемый — будет TypeError (нужны `Object.keys` / `entries`).

### Как перебрать ключи объекта через `for...in`?

```js
for (const key in obj) {
  if (Object.hasOwn(obj, key)) {
    console.log(key, obj[key]);
  }
}
```

### Разница `for...of` и `for...in`?

`for...of` — значения итерируемого. `for...in` — перечисляемые ключи объекта (включая унаследованные).

### Подводные камни `for...in` с массивами и объектами?

Для массивов даёт индексы-строки и может захватить лишние свойства. Для объектов — унаследованные ключи. Лучше не использовать `for...in` для массивов.

### Как `for...in` ведёт себя с унаследованными свойствами?

Перечисляет и их (enumerable в цепочке прототипов). Фильтруй через `Object.hasOwn` / `hasOwnProperty`.

### Что такое итераторы? Связь с `for...of`?

Объект с `next()` → `{ value, done }`. `for...of` вызывает итератор через `Symbol.iterator`.

### Можно ли менять переменную цикла внутри тела?

Да, но легко получить пропуск элементов, бесконечный цикл или путаницу. Лучше менять только в заголовке `for`.

### Как правильно выйти из вложенных циклов?

Метка + `break label`, флаг, `return` из функции, вынести в функцию и выйти `return`.

### Чем цикл отличается от рекурсии? Когда что предпочтительнее?

Цикл — явная итерация, обычно O(1) доп. памяти. Рекурсия — естественно для деревьев/графов, но риск переполнения стека. Для линейных задач чаще цикл.

### Как работает цикл с разреженным массивом (holes)?

`for` по индексу увидит `undefined` в дырках. `for...of` тоже выдаст `undefined`. `forEach`/`map` **пропускают** holes.

### Как перебрать `Map` и `Set` циклами?

```js
for (const [k, v] of map) {}
for (const v of set) {}
map.forEach((v, k) => {});
```

## Объекты

### Что такое объект? Зачем он нужен?

Коллекция свойств «ключ → значение». Для описания сущностей, словарей, настройки, модулей.

### Что может быть ключом / значением?

Ключ: строка или `symbol` (числа приводятся к строке). Значение: что угодно.

### Как получить доступ к свойству?

`obj.key` или `obj["key"]`. Для вычисляемых имён — скобочная нотация.

### Как изменить значение свойства?

`obj.key = value` или `obj["key"] = value`.

### Особенность константы и объекта?

`const obj` нельзя переназначить, но свойства менять можно. «Заморозка» — `Object.freeze`.

### Особенность хранения объектов?

Хранятся и копируются **по ссылке**, не по значению.

### Как копируются объекты?

Присваивание копирует ссылку: `const b = a` — тот же объект.

### Как сравниваются объекты?

`===` сравнивает ссылки. Два разных объекта с одинаковым содержимым не равны.

### Способы клонировать объект

Поверхностно: `{...obj}`, `Object.assign({}, obj)`.  
Глубоко: `structuredClone(obj)`, аккуратный свой обход; `JSON.parse(JSON.stringify(obj))` — с ограничениями.

### Для чего `Object.assign`?

Копирует перечисляемые собственные свойства в целевой объект. Часто для shallow merge/clone.

### Что такое метод объекта? Способы создания?

Функция-свойство объекта. Создание: в литерале `method() {}`, `obj.fn = function(){}`, через `class`.

### Для чего нужны методы?

Поведение, связанное с данными объекта.

### Для чего и как работает `this` в методах?

`this` — объект перед точкой при вызове `obj.method()`.

### Для чего `delete` у объектов?

Удаляет собственное свойство: `delete obj.key`.

### Для чего нужен конструктор объектов?

Шаблон создания однотипных объектов через `new Constructor()`.

### 2 правила для работы конструктора?

1. Вызывать с `new`.  
2. Внутри писать в `this` (не обязательно `return` объект).

### Как работает `return` в конструкторе?

Если вернуть объект — он станет результатом `new`. Если примитив / ничего — вернётся созданный `this`.

### `Object.keys`, `values`, `entries`?

- `keys` — массив ключей  
- `values` — массив значений  
- `entries` — массив пар `[key, value]`  
Только собственные перечисляемые строковые ключи.

## Массивы

### Что такое массив?

Упорядоченная коллекция элементов с индексами от 0 и свойством `length`.

### Какого типа данных массив?

`typeof [] === "object"`. Проверка: `Array.isArray(arr)`.

### Способы создания массива?

`[]`, `new Array(n)`, `Array.from(...)`, `Array.of(...)`, `split` и т.п.

### Как узнать количество элементов?

`arr.length`.

### Как достучаться до элемента?

`arr[index]`, `arr.at(index)` (поддерживает отрицательные).

### Как изменить массив?

Присваивание по индексу, `push`/`pop`/`splice`/`fill` и др. (мутирующие и нет).

### Что может храниться? `pop`/`push`, `shift`/`unshift`, `toString`

Что угодно: числа, объекты, функции, дырки.  

| Метод | Действие | Возврат |
| --- | --- | --- |
| `push(...items)` | в конец | новая length |
| `pop()` | удалить с конца | элемент |
| `unshift(...items)` | в начало | новая length |
| `shift()` | удалить с начала | элемент |
| `toString()` | строка через запятую | string |

### Как перебрать массив?

`for`, `for...of`, `forEach`, `map`, `while`, и т.д.

### `.length` — как работает?

Число элементов / индекс последнего + 1. Можно укоротить массив, записав меньший `length`.

### `delete` в массивах?

Удаляет элемент, оставляя **дырку**; `length` не уменьшается. Лучше `splice`.

### `splice` vs `toSpliced`, `slice`

- `splice(start, deleteCount, ...items)` — **мутирует**, возвращает удалённые.  
- `toSpliced(...)` — то же логически, но **новый** массив.  
- `slice(start?, end?)` — копия участка, без мутации.

### `concat()`

Склеивает массивы/значения в **новый** массив.

### `forEach`, `map`

- `forEach(cb)` — обход ради побочных эффектов, возврат `undefined`.  
- `map(cb)` — новый массив из результатов колбэка.  
Колбэк: `(item, index, array)`.

### `indexOf`, `includes`

Поиск по строгому равенству. `indexOf` → индекс/-1, `includes` → boolean (`NaN` находит).

### `find`, `findIndex`, `filter`, `flat`, `flatMap`

- `find` — первый элемент под условие / `undefined`  
- `findIndex` — индекс / -1  
- `filter` — новый массив прошедших проверку  
- `flat(depth?)` — «разгладить» вложенность  
- `flatMap` — `map` + `flat(1)`

### `sort` vs `toSorted`, `reverse`, `join`, `reduce`, `fill`, `at`

- `sort` — мутирует, по умолчанию как строки; компаратор `(a,b) => a-b`  
- `toSorted` — сортированная копия  
- `reverse` — мутирует, разворот  
- `join(sep)` — строка  
- `reduce(fn, init?)` — свертка к одному значению  
- `fill(value, start?, end?)` — заполнить  
- `at(i)` — элемент по индексу (в т.ч. -1)

### `reverse` vs `toReversed`

`reverse` меняет исходный массив, `toReversed` возвращает новый развёрнутый.

### Для чего `Array.isArray()`?

Надёжно отличить массив от объекта.

### Для чего `thisArg` в методах?

Второй аргумент у `forEach`/`map`/`filter`/`find`… — значение `this` внутри колбэка (для non-arrow функций).

## Другие структуры данных

### Что такое деструктурирующее присваивание? Пример? Где используется?

Распаковка объекта/массива в переменные.

```js
const { name, age } = user;
const [first, second] = arr;
```

Удобно в параметрах функций, импортах, работе с API.

### Как присвоить значение по умолчанию?

```js
const { role = "guest" } = user;
const [x = 0] = arr;
```

### Что такое spread? Где используется?

`...` раскрывает итерируемое/свойства: копирование, склейка, передача аргументов `fn(...arr)`.

### Разница spread и `Object.assign`?

Для объектов оба делают shallow copy/merge. Spread в литерале `{}` выразительнее; `assign` умеет писать в существующий target.

### Копия массива через spread?

```js
const copy = [...arr];
```

### Преимущества spread vs `concat` / `Object.assign`?

Короче, единообразно для массивов и объектов, удобно в литералах, легко вставлять элементы «в середину» логики выражения.

### Можно ли spread со строками?

Да: `[..."hi"]` → `["h","i"]`.

### Что такое rest? Где используется?

Сбор «остатка» в массив/объект: `const [a, ...rest] = arr`, `const {x, ...rest} = obj`, `function f(...args)`.

### Rest с аргументами функции?

`function f(a, b, ...rest)` — `rest` массив всех остальных аргументов.

### `Map` — особенность, методы, обход

Ключи любых типов, сохраняет порядок вставки.  
Методы: `set`, `get`, `has`, `delete`, `clear`, `size`.  
Обход: `for...of`, `forEach`, `keys/values/entries`.

### `Set` — особенность, методы, обход

Уникальные значения.  
`add`, `has`, `delete`, `clear`, `size`.  
Обход: `for...of`, `forEach`.

### `WeakMap` — особенность

Ключи только объекты; слабые ссылки → GC может удалить запись. Нет `size`, нет перебора. Методы: `get/set/has/delete`.

### `WeakSet` — особенность

Только объекты, слабые ссылки, без перебора. `add/has/delete`.

### `Set` vs `WeakSet`

`Set` — любые значения, итерируемый, `size`. `WeakSet` — только объекты, без итерации, слабые ссылки.

### `Map` vs `WeakMap`

Аналогично: `Map` итерируем и с любыми ключами; `WeakMap` — только object-keys и без перечисления.

### Что такое JSON?

Текстовый формат обмена данными (подмножество JS-литералов): объекты, массивы, строки, числа, boolean, `null`.

### `JSON.stringify()` — когда?

Сериализация в строку: отправка на сервер, `localStorage`.

### `JSON.parse()` — когда?

Разбор JSON-строки обратно в значение.

### Для чего `try...catch`?

Ловить исключения в синхронном коде (и в `async` с `await`), не роняя выполнение.

### Что содержит объект ошибки?

Обычно `name`, `message`, иногда `stack`.

### Для чего объект ошибки? `throw`?

Передать информацию о сбое. `throw` генерирует исключение (`throw new Error("...")`).

### Блок `finally`?

Выполняется всегда после `try/catch` — и при успехе, и при ошибке, и при `return` (перед реальным выходом). Для очистки ресурсов.

## Promise, async/await

### Event Loop

JS в браузере однопоточен. Движок крутит цикл:
Выполняет синхронный код (call stack).
Когда стек пуст — сначала microtasks (Promise.then, queueMicrotask, конец async/await).
Потом один macrotask из очереди (setTimeout, setInterval, события DOM, I/O).
Между макрозадачами браузер может отрисовать кадр.
Снова microtasks → следующая macrotask → …
Практический смысл: await / .then продолжаются раньше, чем setTimeout(fn, 0). Долгий синхронный код блокирует и UI, и таймеры.
Использование в проекте: завернуть обработчики ввода инпута в макротаску setTimeout (lodash.debounce)

### Что значит асинхронное действие?

Не блокирует основной поток: результат будет позже (сеть, таймеры, I/O).

### Для чего нужны callback?

Функция, которую вызовут после завершения операции.

### Callback hell. Что это?

Глубокая вложенность колбэков → плохо читается и обрабатываются ошибки.

### Пример callback

```js
setTimeout(() => {
  console.log("done");
}, 1000);
```

### Промисы. Для чего нужны?

Объект результата асинхронной операции: удобные `.then/.catch`, цепочки, меньше callback hell.

### Как создать промис?

```js
const p = new Promise((resolve, reject) => {
  // resolve(value) или reject(error)
});
```

### Параметры? Что возвращает?

Executor `(resolve, reject)`. Конструктор возвращает Promise.

### Свойства и методы промисов?

Состояния: pending → fulfilled / rejected.  
Методы экземпляра: `then`, `catch`, `finally`.  
Статические: `resolve`, `reject`, `all`, `race`, `allSettled`, `any`.

### Цепочка промисов?

`then` возвращает новый промис — можно строить последовательность асинхронных шагов и прокидывать ошибки вниз.

### Что такое промисификация?

Обернуть API на колбэках в функцию, возвращающую Promise.

### `Promise.all`

Ждёт все; если один reject — весь reject. Результат — массив значений.

### `Promise.race`

Результат первого завершившегося (fulfill или reject).

### `Promise.allSettled`

Ждёт все; всегда fulfill с массивом `{status, value|reason}`.

### `Promise.any`

Первый успешный fulfill; если все reject — `AggregateError`.

### Async/await?

Синтаксический сахар над промисами: писать асинхронный код линейно.

### Для чего `async`?

Делает функцию автоматически возвращающей Promise; позволяет использовать `await` внутри.

### Для чего `await`?

Пауза внутри `async`-функции до resolve/reject промиса; возвращает значение или бросает ошибку.

### Что должно стоять справа от `await`?

Thenable/Promise (другое значение станет resolved промисом).

### `try...catch` / объект ошибки / `throw` / `finally` (в async)

Те же идеи: ловить ошибки `await`, смотреть `message`/`name`, пробрасывать `throw`, чистить ресурсы в `finally`.

## HTTP / HTTPS

### Что такое HTTP-запрос и как он работает?

Клиент отправляет запрос (метод, URL, заголовки, тело) на сервер, сервер отвечает статусом, заголовками и телом. HTTPS — то же поверх TLS.

### Что такое `fetch` и чем полезен?

Современный браузерный/Node API для сетевых запросов на промисах: проще, чем `XMLHttpRequest`.

### Какие бывают HTTP-методы и когда применять?

- `GET` — получить  
- `POST` — создать / отправить данные  
- `PUT` / `PATCH` — заменить / частично обновить  
- `DELETE` — удалить  
- `HEAD` / `OPTIONS` — метаданные / CORS preflight  

### Как сделать простой GET через `fetch`?

```js
const res = await fetch("https://api.example.com/items");
const data = await res.json();
```

### Как отправить POST с JSON?

```js
const res = await fetch(url, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "Ann" }),
});
```

### Как обрабатывать ошибки при `fetch`?

`fetch` не reject на 404/500 — только на сеть/CORS. Проверяй `res.ok` / `res.status`, плюс `try/catch` вокруг `await`.

```js
if (!res.ok) throw new Error(`HTTP ${res.status}`);
```

### Чем `fetch` отличается от `XMLHttpRequest`?

Промисы вместо колбэков, проще API, нет прогресса закачки из коробки так же удобно (есть нюансы), по умолчанию не шлёт cookies cross-site так же (credentials настраиваются).

### Что такое CORS и как влияет?

Cross-Origin Resource Sharing — браузер блокирует ответы чужого origin без разрешающих заголовков сервера (`Access-Control-Allow-Origin` и др.).

### Как использовать токены авторизации в `fetch`?

```js
fetch(url, {
  headers: { Authorization: `Bearer ${token}` },
});
```

### Можно ли использовать `fetch` с `async/await`?

Да — это обычный промис: `const res = await fetch(...)`.

## Прототипы, наследование

### Объясните концепцию прототипного наследования в JavaScript

Каждый объект имеет скрытую ссылку на другой объект — прототип. Если свойства нет у самого объекта, движок ищет его по цепочке прототипов (`[[Prototype]]`). Так объекты «наследуют» поведение без копирования методов в каждый экземпляр.

### Для чего нужен прототип?

Чтобы делить общие методы и свойства между многими объектами. Методы лежат на прототипе один раз, экземпляры только ссылаются на него — экономия памяти и единая точка обновления поведения.

### Как присвоить прототип объекту?

```js
const proto = { greet() { return "hi"; } };
const obj = Object.create(proto);           // предпочтительно
Object.setPrototypeOf(obj, proto);          // изменить позже
const obj2 = { __proto__: proto };          // литерал (legacy-стиль)
```

### Что такое `__proto__`?

Геттер/сеттер для доступа к внутреннему `[[Prototype]]` объекта. Удобен для отладки, но в коде лучше `Object.getPrototypeOf` / `Object.setPrototypeOf` / `Object.create`.

### Каким типом может быть значение `__proto__`?

Только объект или `null`. Примитив при присвоении игнорируется; `null` означает «конец цепочки» (как у `Object.prototype`).

### Что такое свойство `prototype` у функций в JavaScript?

У каждой функции (кроме стрелочных) есть свойство `prototype` — объект, который станет `[[Prototype]]` экземпляров, созданных через `new Fn()`. Обычно там кладут общие методы: `Fn.prototype.method = …`.

### Что такое `Object.prototype` и какие методы оно содержит?

Корень почти всех объектов — конец цепочки прототипов. Типичные методы:

- `toString`, `valueOf`
- `hasOwnProperty`
- `isPrototypeOf`
- `propertyIsEnumerable`
- `toLocaleString`

### Как работает `this` для прототипов объекта?

`this` определяется в момент вызова, а не местом объявления метода. При `obj.method()` метод может быть найден на прототипе, но `this` всё равно будет `obj` (тот, у кого вызвали).

### Как задать прототип конструктору?

```js
function Animal(name) { this.name = name; }
Animal.prototype.speak = function () { return this.name; };

function Dog(name) { Animal.call(this, name); }
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;
```

Или через `class Dog extends Animal`.

### Встроенные прототипы у объектов?

Да. Например:

- массивы → `Array.prototype` → `Object.prototype`
- функции → `Function.prototype` → `Object.prototype`
- даты → `Date.prototype`
- строки-объекты → `String.prototype`

У литералов `{}` прототип — `Object.prototype`.

### Прототипы у примитивов? Пример

У примитивов нет собственного объекта-прототипа, но при обращении к методу создаётся временный wrapper:

```js
"hi".toUpperCase(); // временно new String("hi"), метод с String.prototype
(1.5).toFixed(1);   // Number.prototype
true.toString();    // Boolean.prototype
```

### Откуда у примитивов взялись методы и свойства?

Автобоксинг: движок на время вызова оборачивает примитив в объект (`String`/`Number`/`Boolean`) и берёт методы с соответствующего `.prototype`. После вызова wrapper отбрасывается — поэтому `prop` на примитиве не сохраняется.

### Как создать наследование в JavaScript с использованием прототипов?

1. Вызвать родительский конструктор через `Parent.call(this, …)`.
2. Связать прототипы: `Child.prototype = Object.create(Parent.prototype)`.
3. Восстановить `Child.prototype.constructor = Child`.

Современный вариант — `class Child extends Parent`.

### Как проверить, является ли объект экземпляром определенного класса (функции-конструктора)?

```js
obj instanceof Constructor;                 // true/false по цепочке прототипов
Constructor.prototype.isPrototypeOf(obj);
Object.getPrototypeOf(obj) === Constructor.prototype; // только прямой прототип
```

### Как изменить прототип объекта в JavaScript?

```js
Object.setPrototypeOf(obj, newProto); // можно, но медленно для горячих путей
const obj2 = Object.create(newProto); // лучше создать сразу с нужным прототипом
```

`obj.__proto__ = newProto` — устаревший способ.

### Как проверить, существует ли определенное свойство в объекте или его прототипе?

```js
"key" in obj;                    // своё или из прототипа
obj.hasOwnProperty("key");       // только своё
Object.hasOwn(obj, "key");       // современная замена hasOwnProperty
obj.key !== undefined;           // плохо: не отличит отсутствие от значения undefined
```

## Классы

### Как объявить класс? Какие основные блоки есть?

```js
class User {
  field = 1;              // поля экземпляра
  constructor(name) { … } // конструктор
  method() { … }          // методы прототипа
  get x() { … }           // геттер
  set x(v) { … }          // сеттер
  static create() { … }   // статика
  #private = 0;           // приватные поля
}
```

### Для чего нужен `constructor`?

Инициализация экземпляра при `new`: принять аргументы, записать поля, вызвать `super` у наследника. Вызывается автоматически один раз на создание объекта.

### Как работают классы под капотом? Что происходит при создании класса и объявлении методов?

`class` — сахар над функциями-конструкторами. Класс становится функцией `User`, методы пишутся в `User.prototype` (не enumerable), `constructor` — сама эта функция. Поля класса (`field = …`) инициализируются на экземпляре при `new`. Классы не поднимаются как `function declaration` (есть TDZ).

### Как вызвать созданный класс?

Только через `new`:

```js
const user = new User("Ann");
```

Вызов без `new` бросит `TypeError`.

### Что возвращает вызов класса?

`new User(…)` возвращает созданный экземпляр. Если `constructor` явно вернул объект — вернётся он; примитив из `return` игнорируется.

### Геттеры и сеттеры. Для чего?

```js
class Box {
  get size() { return this._size; }
  set size(v) { if (v >= 0) this._size = v; }
}
```

Контролируемый доступ к свойству: валидация, вычисляемые значения, скрытие внутренней реализации. Снаружи выглядят как обычное поле: `box.size = 10`.

### Как создать свойство в классе?

- В `constructor`: `this.name = name`
- Class fields: `name = "default"` / `name;`
- Приватные: `#name = …`
- Статические: `static count = 0`
- Через геттер/сеттер

### Ключевое слово для наследования классов?

`extends`:

```js
class Dog extends Animal { … }
```

### Переопределение методов?

Объявить метод с тем же именем в дочернем классе. Чтобы вызвать родительский — `super.method(…)`.

### Ключевое слово `super`?

Ссылка на родителя: `super.method()` в методах, `super(…)` в конструкторе для вызова родительского `constructor`.

### Переопределение конструктора?

Да — объявить свой `constructor` в наследнике. Обязательно вызвать `super(…)` до обращения к `this`.

### Какой конструктор создается по умолчанию у дочернего класса?

Если не объявлен свой:

```js
constructor(...args) {
  super(...args);
}
```

То есть просто пробрасывает аргументы родителю.

### `super` в конструкторе

У наследника до `super(…)` нельзя использовать `this` / `return`. `super(…)` вызывает конструктор родителя и «подготавливает» экземпляр. В базовом классе `super` в конструкторе не нужен.

### Статические методы и свойства?

Принадлежат самому классу, не экземпляру: `User.create()`, `User.count`. Наследуются через `extends`, доступны как `Child.create()`. Вызов через экземпляр — ошибка/недоступно обычным путём. Внутри статики `this` — сам класс.

### Защищенные свойства. Для чего и как сделать свойство защищенным?

«Защищённые» (convention) — для класса и наследников, не для внешнего кода. В JS нет модификатора `protected`; обычно:

- префикс `_`: `this._token` (договорённость)
- либо `#private` — реально недоступны снаружи и у наследников напрямую
- слабо: `WeakMap` для хранения данных экземпляра

Нужны, чтобы скрыть внутреннее API, но дать наследникам доступ (через `_` или общие методы).

### Для чего придумали примеси? Как реализовать?

Подмешать поведение из нескольких источников, когда одиночного `extends` мало:

```js
const sayHi = (Base) => class extends Base {
  hi() { return "hi"; }
};
class User extends sayHi(Object) {}
```

Или `Object.assign(Target.prototype, mixin)`. Примесь — переиспользуемый набор методов без жёсткой иерархии.

### Множественное наследование в JavaScript?

Нет нативного `extends A, B`. Один прототип / один `extends`. Имитация — примеси, композиция, делегирование другому объекту.

### Инкапсуляция?

Сокрытие внутренней реализации. В классах: приватные поля `#x`, замыкания в фабриках, не экспортировать детали модуля. Снаружи — только публичный API.

### `instanceof`

```js
obj instanceof Class; // true, если Class.prototype есть в цепочке прототипов obj
```

Работает с `class` и function-конструкторами. Для объектов из другого iframe/realm может дать `false` при «том же» классе. Альтернатива узкой проверки: `Object.hasOwn` / уткиная типизация.

## DOM и события

### Можете объяснить концепцию модели документа (DOM)?

DOM (Document Object Model) — объектное представление HTML/XML-документа в памяти браузера. Дерево узлов, которым можно манипулировать из JS: искать, менять, слушать события.

### Структура DOM?

Дерево узлов: `document` → `html` → `head`/`body` → элементы, текст, комментарии. Узлы связаны родитель/дети/соседи. Типы: `Element`, `Text`, `Comment`, `Document` и др.

### Навигация по DOM?

- `parentNode` / `parentElement`
- `childNodes` / `children`
- `firstChild` / `firstElementChild`
- `lastChild` / `lastElementChild`
- `nextSibling` / `nextElementSibling`
- `previousSibling` / `previousElementSibling`

`*Element*` — только элементы; без `Element` — любые узлы (включая текст).

### `childNodes` — что это, что содержит?

Живая коллекция (`NodeList`) всех дочерних узлов: элементы, текстовые узлы (пробелы/переносы), комментарии. Для только тегов удобнее `children` (`HTMLCollection`).

### Что такое живая коллекция?

Коллекция, которая автоматически отражает изменения DOM (`HTMLCollection` у `getElementsBy*`, `childNodes`). `querySelectorAll` возвращает статичный `NodeList` — снимок на момент запроса.

### Какие методы DOM вы знаете для поиска элементов?

- `getElementById`
- `getElementsByClassName`, `getElementsByTagName`, `getElementsByName`
- `querySelector`, `querySelectorAll`
- `closest` (вверх по предкам)
- `matches` (проверка селектора)

### Чем отличается `querySelector` от `querySelectorAll`?

`querySelector` — первый подходящий элемент или `null`.  
`querySelectorAll` — все совпадения (статичный `NodeList`).

### Отличие `getElements*` и `querySelectorAll`?

- `getElements*` — живые `HTMLCollection`, только простые критерии (класс/тег/имя).
- `querySelectorAll` — CSS-селекторы любой сложности, статичный снимок.
- `getElementById` — один элемент по id, не коллекция.

### Как изменить текст содержимого HTML-элемента?

```js
el.textContent = "Hello"; // безопасно, только текст
el.innerText = "Hello";   // учитывает стили/видимость, медленнее
el.innerHTML = "<b>Hi</b>"; // HTML, риск XSS
```

### Как добавить новый элемент в DOM?

```js
const li = document.createElement("li");
li.textContent = "item";
parent.append(li);        // или appendChild, prepend, before, after
```

### В чем разница между `element.append()` и `element.appendChild()`?

- `append` — несколько аргументов, принимает узлы и строки, возвращает `undefined`.
- `appendChild` — только один узел, возвращает вставленный узел.
- `append` новее и удобнее.

### Как удалить элемент из DOM?

```js
el.remove();
parent.removeChild(el);
```

### Какой метод используется для создания нового элемента в DOM?

`document.createElement("div")`. Для текста — `document.createTextNode("…")`. Для разметки из строки — `template` / `insertAdjacentHTML` (осторожно с XSS).

### Как вставить элемент перед другим элементом в DOM?

```js
parent.insertBefore(newNode, referenceNode);
referenceNode.before(newNode);
referenceNode.insertAdjacentElement("beforebegin", newNode);
```

### В чем разница между `innerHTML` и `innerText`?

- `innerHTML` — HTML-разметка как строка (парсинг тегов).
- `innerText` — видимый текст с учётом CSS (не берёт `display:none`), триггерит reflow.
- Для простого текста обычно лучше `textContent`.

### Какой метод используется для клонирования узла?

```js
const copy = el.cloneNode(true); // true — глубокое клонирование с детьми
```

Обработчики, навешанные через `addEventListener`, не копируются.

### Работа с классами на элементах DOM?

```js
el.classList.add("active");
el.classList.remove("active");
el.classList.toggle("active");
el.classList.contains("active");
el.classList.replace("old", "new");
```

`className` — строка целиком (менее удобно).

### Что такое событие в контексте DOM и как его можно обработать?

Сигнал о действии пользователя или браузера (`click`, `input`, `submit`…). Обработка: `el.addEventListener("click", handler)` или `el.onclick = handler`. В handler приходит объект события `event`.

### Что такое делегирование событий в JavaScript?

Вешаем один слушатель на общего предка и обрабатываем события детей через всплытие:

```js
list.addEventListener("click", (e) => {
  const item = e.target.closest("li");
  if (!item || !list.contains(item)) return;
  // обработка item
});
```

Плюсы: меньше обработчиков, работают и для динамически добавленных элементов.

### Как называется процесс прослушивания событий в JavaScript?

Event listening / подписка на события: регистрация listener’ов, которые вызываются при наступлении события.

### Как можно добавить обработчик события к элементу в JavaScript?

```js
el.addEventListener("click", handler);           // предпочтительно
el.addEventListener("click", handler, true);     // на фазе capture
el.addEventListener("click", handler, { once: true, passive: true });
el.onclick = handler;                            // одно свойство-обработчик
```

### Какие способы удаления обработчика события из элемента вы знаете?

```js
el.removeEventListener("click", handler); // нужна та же ссылка на функцию и те же capture-флаги
el.onclick = null;                        // для property-handler
AbortController: signal → abort()         // если слушатель создан с { signal }
```

Анонимную функцию снять нельзя — сохраняйте ссылку.

### Что такое объект события в JavaScript? Какие свойства он содержит?

Объект с данными о событии, передаётся в handler. Часто используют:

- `type`, `target`, `currentTarget`
- `clientX` / `clientY`, `key`, `code`
- `preventDefault()`, `stopPropagation()`, `stopImmediatePropagation()`
- `bubbles`, `defaultPrevented`, `eventPhase`
- `timestamp`

### Фазы события? Для чего?

Три фазы: capturing → target → bubbling. Нужны, чтобы решать, на каком уровне дерева и в каком порядке ловить событие. Capture (`addEventListener(…, true)`) — до цели; bubble — после. Делегирование обычно опирается на bubbling.

### Как остановить всплытие события в JavaScript?

```js
e.stopPropagation();          // дальше по дереву не пойдёт
e.stopImmediatePropagation(); // плюс другие слушатели на этом же элементе
```

На уже вызванные слушатели на текущем узле `stopPropagation` не откатывает.

### Как можно отменить действие по умолчанию при возникновении события? Где применяется?

```js
e.preventDefault();
```

Отмена поведения браузера: переход по ссылке, submit формы, контекстное меню, drag-and-drop и т.п. На фазы не влияет. Для части событий нужен не-`passive` listener (например `touchmove`).

### Как можно создать и инициировать пользовательское событие в JavaScript?

```js
const ev = new CustomEvent("user:save", {
  detail: { id: 1 },
  bubbles: true,
  cancelable: true,
});
el.dispatchEvent(ev);
```

Либо `new Event("open")` без `detail`. Слушают обычным `addEventListener("user:save", …)`.

### Погружение и всплытие событий

При клике событие проходит DOM в три этапа:

1. **Capture (погружение)** — сверху вниз: `window` → … → родитель → цель.
2. **Target** — на самом элементе.
3. **Bubble (всплытие)** — снизу вверх: цель → родители → `document`.

- `e.stopPropagation()` — остановить дальнейшее распространение по дереву.
- `e.preventDefault()` — отменить действие браузера (переход по ссылке, submit и т.п.); на фазы не влияет.

В проекте чаще работаем со всплытием и при необходимости его останавливаем. Пример: закрытие окна редактирования кликом по оверлею — чтобы клик не ушёл к обработчикам под ним. Типичный кейс: клик по строке открывает попап редактирования, клик по кнопке удаления — диалог удаления (`stopPropagation` на кнопке, чтобы не открыть оба).
